# 拂尘 · Dusted

酒馆批量清理插件。角色卡、世界书、人设、背景图、美化主题、预设，在一个面板里看预览、多选、真删除。

## 安装

酒馆 → 扩展 → 安装扩展 → 填入仓库链接。

装好后从左下角魔杖菜单里的「拂尘」打开，或者在扩展设置里找到「拂尘 · Dusted」。

## 用法

- 点一项：看详情和它被谁引用
- 长按一项，或点右上角的勾：进入多选
- 多选时点「全选闲置」：一键选中所有闲置的
- 右上角太阳/月亮：切换日间和夜间，默认跟随手机系统

## 删角色卡时会一起清理

- 聊天记录
- 随卡导入的世界书（被其他卡、全局、人设用着的会保留）
- 正则授权记录、标签关联、群聊成员、人设关联
- 缩略图缓存

删完会重新读取一遍酒馆数据，核对文件是不是真的没了，没删掉的会列出来。

## 备份

默认删之前先把要删的东西打成 zip 下载到你自己的设备，不占酒馆服务器空间。超过 80 MB 会分成几个包。
找回时用酒馆自带的导入功能导入对应文件就行。

## 注意

- 正在用的角色、人设、背景、主题、预设不能删，先切走再删
- 锁定在某个聊天里的背景检测不到
- 删主题、预设、背景、人设后，酒馆里的下拉菜单要刷新页面才同步

兼容 SillyTavern 1.14 – 1.19。
